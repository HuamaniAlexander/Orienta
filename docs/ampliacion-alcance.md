# Ampliación autorizada

El pedido posterior autoriza completar también comparador, entrenamiento y análisis ML,
orientaciones y fusión de los PR sin conflictos hacia dev. Sustituye la restricción anterior
de no fusionar. No autoriza publicar una versión ni desplegar a producción.

Las ramas hu04-comparador, hu05-vista-ligera, hu-ia01-explicacion y pruebas-pdca continúan
la cadena de dependencias. Se integran mediante PR con merge commit y SHA esperado,
después de verificar ausencia de conflictos y las pruebas aplicables.

El análisis IA se limita al contraste de áreas que define el material S9. Las orientaciones
para verificar fuentes y las diferencias numéricas se identifican como resumen de datos.
El sistema no simula respuestas de un LLM ni recomienda una carrera como adecuada para
una persona sin datos y evaluación que lo sustenten. Las alternativas relacionadas usan
similitud de contenido; no un diagnóstico vocacional.

La interfaz elimina el aviso global de demostración. Conserva la condición estimada de
los costos, las fuentes, las fechas y los datos faltantes. El catálogo inicial incluye las
19 ofertas suministradas; se amplía importando registros documentados, nunca inventados.
No se certifica haber completado las 80 tareas ni las pruebas con usuarios reales.
